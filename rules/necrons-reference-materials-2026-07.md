## July changes relevant to this list

- Canoptek Reanimator increased by 5 points, from 70 to 75.
- The supplied 1995-point list is therefore exactly 2000 points under MFM
  v1.1. No other unit or enhancement in the supplied list is marked as
  changed in the current MFM.
- A slain Character that revives now returns as its own one-model unit
  instead of rejoining its previous Attached unit. This directly affects
  uses of Awakened Dynasty's Character-revival rule.
- Outside the normal Command phase CP, a player can gain only one additional
  CP per battle round. This matters for Imotekh and any other CP-generation
  source used alongside him.
- A unit can make only one Normal Move per phase.
- Stacked hit/BS debuffs were generally restricted; intentional exceptions
  remain.
- Some Necron Arks gained the Frame keyword, but this army contains no Arks.
- First-turn Deep Strike permissions were clarified; none of the units in
  the supplied list has a list-specific July points change tied to that
  clarification.
